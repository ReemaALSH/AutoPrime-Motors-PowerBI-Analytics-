# 🚗 AUTOPRIME Motors — Executive Sales & Operations Analytics

An end-to-end Power BI analytics solution designed for an automotive sales network analyzing **45K+ customer records** and **$36B+ in revenue** across 6 regional branches.

## 🛠️ Key Technical Features

- **Star Schema Data Modeling:** Built an optimized dimensional model connecting sales transactions, customer demographics, inventory status, and branch targets.
- **Advanced DAX Calculations:** Authored dynamic measures for performance KPIs, inventory turnover rates, MoM growth, and branch ranking logic.
- **Custom JSON Branding:** Designed and implemented a custom JSON theme (`AutoPrime_Theme.json`) adhering to corporate royal blue and amber branding.
- **Interactive Visualizations:** Integrated dynamic slicers, drill-through pages, and visual tooltips for executive decision-making.
